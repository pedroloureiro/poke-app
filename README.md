📱 PokeApp — Android Learning Project
PokeApp is a personal Android project built with the goal of learning modern mobile development using Jetpack tools and best practices.
It uses the public PokéAPI to fetch Pokémon data and present it in a clean, user-friendly interface.

🚀 Project Goals
This project is not just about building an app — it's about building the right way.

Learn and apply modern Android development practices
Master the Jetpack ecosystem (Compose, ViewModel, Navigation, etc.)
Build scalable, maintainable, and testable code
Work with real-world API data
Improve UI/UX design skills

🧠 Learning Approach
Before diving fully into PokeApp, I’m completing official Android training from Android Developers:

Android Developer Codelabs
Fundamentals of Kotlin & Android
Jetpack Compose basics
Architecture patterns (MVVM)

These exercises serve as the foundation for building this app properly.

🛠️ Tech Stack
Language: Kotlin
UI: Jetpack Compose
Architecture: MVVM
Networking: REST API integration
Async: Coroutines / Flow
Dependency Injection: (Planned: Hilt)
Navigation: Jetpack Navigation
Image Loading: (e.g., Coil or Glide)
📡 API

All Pokémon data is provided by:
